# AgentTaskBoard

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
AI 에이전트에게 업무를 위임하는 것이 일상이 된 2026년, 비개발자 직장인이 복잡한 코딩 없이 AI 에이전트 업무 파이프라인을 시각적으로 설계·실행·모니터링하는 노코드 오케스트레이션 툴

## Problem
Cursor·Claude Agent·n8n 등 AI 에이전트 툴이 쏟아지지만, 비개발자가 쓰기엔 여전히 코드·API 이해가 필요함. '엑셀 데이터 정리 → 요약 리포트 → 이메일 발송' 같은 반복 업무를 AI에게 맡기고 싶은데 자동화 설정이 너무 복잡. 기존 RPA 툴(Zapier 등)은 영어에 비쌈.

## Target Users
반복 업무 자동화에 관심 있는 비개발자 직장인(기획·마케팅·운영), AI 에이전트를 업무에 도입하려는 스타트업 운영팀, Zapier·Make 대비 저렴한 한국어 대안을 찾는 소규모 사업자

## Core Features
1. 드래그&드롭 업무 플로우 빌더(트리거→AI처리→액션 3단계 시각화)
2. 한국 서비스 네이티브 연동(카카오톡 발송, 네이버 캘린더, 구글 스프레드시트)
3. 자연어로 플로우 생성('매일 오전 9시 뉴스 요약해서 슬랙에 보내줘' 입력 → 자동 설정)
4. 실행 로그 및 에러 알림 대시보드
5. 커뮤니티 플로우 템플릿 공유 마켓(검증된 자동화 레시피 제공)

## Monetization
- Model: freemium_subscription
- Estimated MRR: $2,600
- Reasoning: 무료: 월 100회 실행 / 스타터 ₩19,000/월: 1,000회 / 프로 ₩49,000/월: 무제한 + 고급 연동. Zapier 한국 대안 수요 확인됨(한국어 지원·가격 불만). 스타터 70명 + 프로 30명 목표. B2B 소규모팀 구독 확장성 있음.
